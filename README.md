# 어잉티기보플레이어

어잉티연구소(Eoingtilab)가 개발한 웹용 바둑 기보 플레이어입니다. SGF 읽기, 바둑판 렌더링, 재생 컨트롤, 해설 자막 및 총보 인쇄 코드를 이 저장소에서 공개합니다.

[웹 플레이어 실행](https://eoingtilab.github.io/Eoing-gibo/)

브라우저에서 착수, 포획, 본보 재생과 놓아보기를 처리합니다. 첫 화면에서 9줄 예제 기보와 실제 KataGo 분석을 볼 수 있습니다.

## 컨트롤러 로고 제거·교체 (유료)

컨트롤러 오른쪽의 어잉티 기보플레이어 로고를 제거하거나 기관·서비스의 로고로 교체하려면 사전에 어잉티연구소의 유료 승인을 받아 주세요. 비용과 적용 범위는 이메일로 안내합니다. [master@eoingti.com](mailto:master@eoingti.com)

로고를 무단으로 삭제하거나 교체해 저작권을 침해하면 손해배상 등 민사상 책임을 질 수 있습니다. 해당 표시가 법에서 정한 권리관리정보에 해당하고, 업으로 또는 영리를 목적으로 권리 침해를 유발하거나 은닉한다는 사실을 알면서 무단으로 제거·변경하는 등 법정 요건을 충족하면 형사처벌 대상이 될 수 있습니다. [저작권법 제104조의3 및 제136조](https://www.law.go.kr/LSW/lsInfoP.do?lsId=000798)

## 실행

저장소 루트에서 `python -m http.server 8000 --bind 127.0.0.1`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. 정적 웹 호스팅에도 그대로 배포할 수 있습니다. 개인 SGF와 분석 파일은 파일 선택기로 열면 브라우저에서 처리됩니다.

## 복기

밝은 판과 어두운 판, 착수음 설정을 기억합니다. 바둑판에 포커스를 두고 방향키로 한 수씩, Home과 End로 처음과 끝으로 이동할 수 있습니다. 놓아보기에서 한 수씩 무르거나 본보로 복귀할 수 있습니다. 인쇄는 주 진행도 전체의 착수 번호, 중복 착점 및 패스를 표시합니다.

UTF-8, BOM이 있는 UTF-16, 한국어 CP949/EUC-KR 및 지원되는 SGF 문자셋 선언을 읽습니다. 선언이 없는 오래된 한국 기보는 UTF-8과 한국어 디코딩을 시도합니다. 일본어·중국어 등의 선언 없는 기보는 문자 인코딩 메뉴에서 선택할 수 있습니다. SGF 주 진행도를 재생하며 해설은 해당 수의 C 속성을 표시합니다.

## AI 승부예측 · 형세 · 해설

공식 KataGo 실행 파일, 분석 설정과 신경망 파일을 준비합니다. Node.js 20 이상에서 아래 명령을 실행합니다. 덤과 규칙은 대국 조건에 맞춥니다. 마지막 값은 한 국면의 탐색 횟수입니다.

```sh
node tools/analyze.mjs game.sgf game.json /path/to/katago /path/to/analysis.cfg /path/to/model.bin.gz korean 6.5 64
```

웹에서 SGF와 생성된 JSON을 선택합니다. 기보 내용이 달라지면 분석 파일 일치 여부를 다시 확인합니다. 그래프를 누르면 해당 수로 이동합니다. 형세 보기에서 검은 점과 흰 점은 각 빈자리의 예상 소유권을 표시합니다. 승률과 예상 집 차이는 흑 기준으로 저장합니다. 탐색 횟수와 모델에 따라 추정이 달라집니다.

해설 자막은 작성자의 SGF 해설을 우선 표시합니다. 해당 수에 해설이 없으면 AI 분석값으로 예상 집 차이와 승률 변화를 설명합니다. 분석 파일이 없으면 실제 착수와 포획을 표시합니다. 놓아보기에서는 본보 해설을 숨깁니다.

분석 도구와 모델은 [KataGo 공식 배포](https://github.com/lightvector/KataGo)에서 받을 수 있습니다. 예제 분석은 KataGo v1.16.3과 g170e-b20c256x2-s5303129600-d1228401921 모델로 생성했습니다.

## 기보 등록 시 자동 분석

게시판에 연결할 때는 서버에 대기 폴더와 결과 폴더를 만들고 아래 작업을 한 개 실행해 둡니다. 두 폴더는 서로 다른 경로를 사용하세요. 대기 폴더는 공개 웹 경로 밖에 두고, 결과 폴더의 JSON은 플레이어에서 읽을 수 있게 합니다.

```sh
node tools/worker.mjs /path/to/queue /path/to/results /path/to/katago /path/to/analysis.cfg /path/to/model.bin.gz
```

- 게시판에서 SGF 저장에 성공하면 **원본 바이트의 SHA-256**을 구합니다. 결과 폴더에 같은 해시의 `.json`이 있으면 그대로 사용합니다.
- 새 원본은 대기 폴더에 임시 이름으로 쓰고, 쓰기를 마친 뒤 `<해시>.sgf`로 공개합니다. 작업은 파일 생성 알림을 받아 국면당 16회 탐색으로 분석하고, 완료된 결과를 `<해시>.json`으로 저장합니다. 게시판 제목이나 설명만 바꿀 때는 작업을 요청할 필요가 없습니다.
- 작업을 재시작하면 남은 대기 파일부터 처리합니다. DB 일괄 이전 후에는 게시물과 첨부파일을 한 번 대조해 결과가 없는 원본만 같은 방식으로 넣습니다. 페이지 조회나 주기적인 전체 DB 검색은 필요하지 않습니다.
- 규칙이 생략된 기보는 한국 규칙을, 덤이 생략된 기보는 일반 대국 6.5집과 접바둑 0.5집을 기본값으로 사용합니다. 다른 조건으로 분석하려면 위의 단일 기보 명령에서 규칙과 덤을 지정하세요.
